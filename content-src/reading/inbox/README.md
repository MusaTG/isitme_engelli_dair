# inbox — dışarıda üretilen okuma metinleri buraya

Klasör yapısı: `inbox/<dil>/<kategori>/<herhangi-bir-ad>.txt`

```
inbox/
  tr/dialogue/parti-01.txt
  tr/work/eposta-1.txt
  en/stories/batch-03.txt
```

Dil: `tr`, `en`. Kategori: `daily stories novel news info travel dialogue work poetry language kids longform letters critical`.

Sonra `npm run reading:import` (GitHub'da: yayın iş akışı kendisi çalıştırır). Rapor: `RAPOR.md`. Biçim ve ayrıntılar: `docs/reading-format.md`. Hazır istemler: `docs/reading/istemler/`. Şablon: `content-src/reading/sablon.txt`.
